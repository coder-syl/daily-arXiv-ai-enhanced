### [1] [STATERA: Hidden Mass Estimation via Zero-Shot Sim-to-Real Kinematics using Frozen Temporal Tubelets](https://arxiv.org/abs/2610.00003)
*Animesh Varma*

Main category: cs.CV

TL;DR: 本文提出STATERA方法，利用预训练视频模型（V-JEPA）和轻量时序模块，从单目短视频中估计不透明非对称刚体的质心位置，并构建HiddenMass基准数据集。实验表明该方法在仿真和零样本迁移到真实场景中显著优于基线，在物理合理性方面提升明显。

  <summary>Details</summary>
Motivation: 现有基于帧级外观预训练的视觉模型难以从运动中推断隐藏的物理属性（如质心），尤其在自遮挡导致表面线索和点跟踪不可靠的情况下。因此，作者希望探索如何利用时序信息和预训练模型来解决这一挑战。

Method: 提出STATERA框架：冻结大部分预训练视频主干网络（V-JEPA）权重，加入轻量级时序tubelet mixer，预测每帧质心热图与轨迹；同时构建包含5万MuJoCo轨迹和63段真实视频的HiddenMass基准。

Conclusion: 冻结的时序表征能更有效地将惯性动力学与视觉几何分离，有助于隐藏物理参数（如质心）的估计，且相位感知监督对捕捉真实物理偏移至关重要。

In zero-shot sim-to-real transfer, we observe a fundamental trade-off in supervision: phase-aware targets can induce bimodal predictions, while phase-agnostic targets can collapse toward statistically safe centroids. Nevertheless, our phase-aware STATERA-50K-Crescent is the only evaluated method that demonstrates consistent movement toward the true hidden offset. While this leads to a monocular vector overshoot artifact that marginally increases absolute Euclidean error compared to a static geometric centroid, it improves physics capture from 2.6% to 41.0%. ### [2] [Emergent Object Binding Has a Finite Spatial Horizon](https://arxiv.org/abs/2610.00006)
*Mayank Singal*

Main category: cs.CV

TL;DR: 预训练视觉Transformer能编码图像块是否属于同一物体，该信号具有局部性且随距离呈指数衰减，揭示了对象绑定的内在结构。


<details>
  <summary>Details</summary>
Motivation: 探究预训练视觉Transformer中是否存在对象绑定（即判断两个图像块是否属于同一物体）的隐式表示，并理解其结构性质而非仅依赖整体准确率。

Method: 通过冻结的patch嵌入使用多种探针在ADE20K和COCO数据集上解码IsSameObject信号，分析绑定概率随空间距离的变化规律，并控制混杂变量系统评估不同条件下的绑定行为。

Result: 发现绑定信号具有局部性，随patch间距离呈指数衰减并趋于非零基线；该现象在不同模型（DINO、CLIP）、数据集和探针下一致。绑定在大物体上减弱，对同类不同物体区分能力较弱，但能有效关联部件与整体，且不受遮挡影响（控制物体大小后）。

Conclusion: 对象绑定是预训练视觉表征的固有属性，表现为有限范围的局部空间一致性，单一准确率指标掩盖了其丰富结构；初步观察还暗示DINOv2/v3中不同深度层可能编码不同尺度的绑定信息。

Abstract: Pretrained Vision Transformers encode whether two image patches belong to the same object. This IsSameObject signal is decodable from frozen patch embeddings at high accuracy, which suggests that object binding emerges from self-supervised pretraining alone. We show that this single accuracy number hides the structure of the signal. Binding is local: the probability that two patches of the same object are decoded as bound falls off monotonically with the distance between them and levels off at a nonzero floor, a falloff well described by an exponential with a finite length scale. This decay holds across object sizes, across three families of probe, on both ADE20K and COCO, and across DINO and CLIP backbones, which indicates that it is a property of the representation rather than of the decoder. Reading binding as local spatial coherence with a finite range accounts for a set of behaviors that the aggregate score leaves unexplained: binding weakens on large objects, separates distinct objects of the same class less reliably than objects of different classes, and groups object parts with their wholes. It is, by contrast, unaffected by occlusion once object size is controlled. We map each behavior with confounds controlled. As a preliminary observation, the horizon and its floor are organized at different depths in DINOv2 and DINOv3, which we report as suggestive given the small number of layers probed and the confound between the two models.

Abstract (中文翻译): 预训练的视觉Transformer能够编码两个图像块是否属于同一物体的信息。这种“是否为同一物体”（IsSameObject）信号可以从冻结的图像块嵌入中以高准确率解码出来，表明仅通过自监督预训练即可涌现出对象绑定能力。我们指出，这一单一的准确率数字掩盖了信号的内在结构。绑定具有局部性：属于同一物体的两个图像块被正确解码为绑定的概率，会随着它们之间距离的增加而单调下降，并最终趋于一个非零的基线值，这种衰减过程可用具有有限长度尺度的指数函数很好地描述。该衰减规律在不同物体尺寸、三类探针方法、ADE20K与COCO两个数据集，以及DINO和CLIP两种骨干网络中均成立，表明这是表征本身的属性，而非解码器所致。将绑定理解为具有有限范围的局部空间一致性，可以解释一系列整体得分无法说明的行为：绑定在大物体上变弱；对同类不同物体的区分不如对不同类物体可靠；但能有效将物体部件与其整体关联起来。相比之下，在控制物体大小后，遮挡对绑定几乎没有影响。我们在控制混杂因素的前提下系统地刻画了上述每种行为。作为初步观察，我们发现DINOv2和DINOv3中“视界”（horizon）及其基线值出现在不同网络深度，鉴于所探测层数较少且两个模型存在混杂因素，我们仅将此结果作为启发性发现予以报告。
